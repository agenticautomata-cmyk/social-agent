Engineering highlightsWhat's interesting under the hood

State-machine in Postgres

Workers claim with FOR UPDATE SKIP LOCKED — horizontal scaling, automatic crash recovery, free retries.

HITL → autonomous flip

Boot in HITL approval mode. One config flag flips a campaign to auto. Same code path, same approval gate.

pgvector dedup

Topics embedded with text-embedding-3-small. Cosine distance against last 90 days. Regenerates if max similarity > 0.85.

Real ffmpeg post-prod

SRT subtitle burn. Hook + CTA overlays. TikTok-spec H.264/AAC normalization. All gated by DEMO_MODE.

Multi-account routing

Per-platform groups with three strategies: fan-out, round-robin, or weighted-random. Tracks usage for fairness.

Analytics feedback loop

IG Insights + TikTok Display API → post_metrics → topic_performance → planner_weight_modifier. Closed loop.

StackProduction-credible primitives

  • Postgres 16 + pgvector + uuid-ossp + citext + pg_trgm — 11 tables, 13-state strict-forward state machine, 1536-dim embeddings with ivfflat ANN index
  • TypeScript monorepo (pnpm workspaces) — services/core (Drizzle ORM, providers), services/workers, services/api (Hono), dashboard (Next.js 15)
  • n8n for orchestration — three importable workflows for cron, Slack approval routing, publishing health monitor
  • External integrations — OpenAI scripts/embeddings, HeyGen avatar render, Google Imagen portraits, Pexels B-roll, IG Graph API + TikTok Direct Post — every one gated behind DEMO_MODE with a mock implementation that ships realistic data with realistic delays
